# Ore Excavation Auto

Мод для Minecraft 1.21.1 (NeoForge), который автоматически нажимает клавишу мода **Ore Excavation** при разрушении блоков руды.

Текущая версия: **1.3.3**.

## Описание

Этот мод позволяет автоматически активировать функцию массовой добычи мода Ore Excavation, когда вы ломаете блок руды. Вам больше не нужно держать нажатой клавишу `~` — мод сделает это за вас.

## Требования

- **Minecraft**: 1.21.1
- **NeoForge**: 21.1.85 или новее
- **Ore Excavation** (или совместимый мод): обязателен на стороне хоста/сервера
- **Этот мод**: устанавливается только на клиенте игрока
- **Java**: 21

> Ore Excavation должен быть установлен именно на сервере или у хоста локальной игры.
> Только установить Ore Excavation у вас на клиенте недостаточно для автоматической
> вскопки чужого или хостингового сервера.

## Установка

1. Установите [NeoForge 1.21.1](https://neoforged.net/) для Minecraft 1.21.1
2. Убедитесь, что Ore Excavation установлен на сервере или у хоста локальной игры
3. Скопируйте файл `.jar` этого мода в папку `mods` вашего клиента Minecraft
4. Запустите игру

## Сборка из исходного кода

```bash
# Клонируйте или распакуйте проект
cd oreexcavation-auto

# Запустите сборку через Gradle
./gradlew build

# Готовый .jar будет в папке build/libs/
```

## Управление

| Клавиша | Действие | По умолчанию |
|---------|----------|--------------|
| `G` | Включить / выключить авто-вскопку | G |
| `H` | Открыть меню настроек | H |

> Клавиши можно изменить в **Настройках игры → Управление → Авто Вскопка Руды**

## Меню настроек (клавиша H)

- **Кнопка включения/выключения** — быстро включить или отключить мод
- **Вкладка «Белый список»** — блоки, для которых вскопка всегда активируется
- **Вкладка «Чёрный список»** — блоки, для которых вскопка никогда не активируется (приоритет выше белого списка)
- **Полный список блоков реестра** — любой блок можно выбрать и добавить в нужный список одним нажатием
- **Поле поиска** — фильтрация блоков по идентификатору или имени
- **Кнопка «+ Добавить смотримый блок»** — добавить блок, на который вы сейчас смотрите
- Повторное нажатие на выбранный блок удаляет его из списка

## Как работает автоопределение

По умолчанию мод активирует вскопку для любого блока, в идентификаторе которого содержится слово `ore` (например, `minecraft:iron_ore`, `minecraft:deepslate_gold_ore`, `create:zinc_ore` и т.д.).

Это поведение можно изменить в конфигурационном файле `oreexcavationauto-client.toml`.

## Конфигурационный файл

Файл находится по пути: `.minecraft/config/oreexcavationauto-client.toml`

```toml
[general]
    # Включить или выключить авто-вскопку
    enabled = true

    # Автоматически активировать для блоков, в ID которых есть "ore"
    autoDetectOreInId = true

    # Белый список: блоки, для которых всегда активируется вскопка
    whitelist = []

    # Чёрный список: блоки, для которых вскопка никогда не активируется
    blacklist = []
```

## Технические детали

Мод работает следующим образом:
1. При ЛКМ или автоматической добыче Baritone мод проверяет реальную выбранную цель
2. Камень и остальные непреимпотентные блоки не отправляются в Ore Excavation
3. При совпадении с авто-определением или белым списком мод отправляет нативный пакет вскопки
4. Каждый блок запрашивается повторно не чаще чем раз в 40 тиков, а чёрный список всегда имеет приоритет
5. Ore Excavation на сервере или у хоста выполняет реальную вскопку жилы

Наш мод не заменяет Ore Excavation и не выполняет разрушение блока самостоятельно.
Для работы в локальной игре или на сервере Ore Excavation должен быть установлен
на стороне хоста/сервера.

## Возможные проблемы

- **Вскопка не работает**: убедитесь, что мод Ore Excavation установлен. В логах (`latest.log`) должна быть строка `Found Ore Excavation key: ...`
- **Клавиша не найдена**: мод совместим с `key.oreexcavation.excavate` и `key.excavated_variants.excavate`. Если ваш мод использует другое имя клавиши, создайте issue.
- **Конфликт клавиш**: измените клавиши мода в настройках управления
